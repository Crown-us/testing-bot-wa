BAGIAN 2: PERSIAPAN SEBELUM JALANKAN PROGRAM
================================================================================

STEP 1: Cek file yang dibutuhkan
─────────────────────────────────

Pastikan di folder lo ada:

  📁 Folder Project/
     ├── WAWeb.js              ← WAJIB ADA (file utama ~6.8MB)
     ├── interaktif-waweb.js   ← Opsional (basic version)
     └── interaktif-waweb-deep.js ← Opsional (deep version)

STEP 2: Install Node.js
────────────────────────

Kalau belum punya Node.js, install dulu:
- Download dari https://nodejs.org
- Pilih versi LTS (Long Term Support)
- Install seperti biasa

STEP 3: Buka Terminal/Command Prompt
─────────────────────────────────────

Windows:
  tekan Win + R, ketik "cmd", ENTER

Atau pakai PowerShell:
  tekan Win + X, pilih "Terminal" atau "PowerShell"

STEP 4: Navigasi ke folder project
───────────────────────────────────

Misalnya folder lo di D:\test-ilmu-orang

  cd D:\test-ilmu-orang

Atau kalau udah di folder yang bener, langsung aja.

─────────────────────────────

1. Baca materi sekali tanpa fokus detail
2. Jalankan program dan follow setiap step
3. Catat hal-hal penting
4. Repeat untuk materi yang belum paham
5. Praktik dengan custom search


TIPS 3: Troubleshooting
───────────────────────

MASALAH: "File tidak ditemukan"
  → Pastikan WAWeb.js ada di folder yang sama
  → Cek dengan: ls -la (Linux/Mac) atau dir (Windows)

MASALAH: "Node.js tidak ditemukan"
  → Install Node.js dari https://nodejs.org
  → Restart terminal setelah install
